# Stone Paper Scissors Game 🎮

A simple **Stone, Paper, Scissors** game written in **C language**.
The program allows you to play against the computer with randomized choices.

---

## Features ✨

* User vs Computer gameplay
* Randomized computer moves
* Input validation for wrong entries
* Replay option to play multiple rounds

---

## How to Run 🚀

1. Clone the repository or copy the code into a file (e.g., `sps.c`).
2. Compile the program:

   ```bash
   gcc sps.c -o sps
   ```
3. Run the executable:

   ```bash
   ./sps
   ```

---

## Game Rules 📜

* **Stone beats Scissors**
* **Scissors beat Paper**
* **Paper beats Stone**
* If both choose the same → It's a **draw**

---

## Example Gameplay 🕹️

```
Stone Paper Scissors Game
1. Stone
2. Paper
3. Scissors
Enter your choice (1-3): 1
You chose: Stone
Computer chose: Scissors
You win!
```
